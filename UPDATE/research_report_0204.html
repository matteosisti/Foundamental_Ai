Experimental setup
ERFNet pixel-based

Pretrained on Cityscapes (19+1 classes). Input 1024×512. Methods: MSP, MaxEntropy, MaxLogit. Weights from professor's repo.

EoMT Base 640×640

ViT-Base/14 DINOv2 backbone. Checkpoint: eomt_cityscapes.bin from HuggingFace tue-mps/cityscapes_semantic_eomt_base_640. Methods: MSP, MaxEntropy, MaxLogit, RbA.

EoMT Large 1024×1024

ViT-Large/14 DINOv2 backbone. Checkpoint: eomt_large_1024.bin from HuggingFace tue-mps/cityscapes_semantic_eomt_large_1024. Simple resize inference (no sliding window).

Infrastructure

A100 80GB GPU (Colab Pro+). Temperature sweep offline from cached logits. All results float32, seed=0, deterministic mode.

MSP Large 1024 wins on RA21 and RA — large anomaly datasets where higher resolution helps discriminate. RA21 MSP: 37.52% → 87.36%.
MaxEntropy and RbA degrade severely — FPR95≈100% on most datasets. Hypothesis: simple square resize distorts aspect ratio of non-square images (especially RO21, LAF), corrupting the road-area evaluation mask. Sliding window inference may fix this.
MaxLogit Base 640 still better on LAF, fs_static, RA — the Base model at lower resolution outperforms Large 1024 on these challenging small-obstacle datasets.
Open questions and next steps
  • 01 Sliding window inference — does using window_imgs_semantic from the professor's repo fix the aspect ratio distortion and recover RbA/MaxEntropy performance on Large 1024? Awaiting professor reply on Discord.
  • 02 GT mask resize bug — current load_ood_mask does a square resize which distorts the road-area void mask for RO21 and LAF. Need to implement aspect-ratio-preserving resize with padding to correctly handle void pixel boundaries.
  • 03 Script fix — collect_results.py picks wrong run for ERFNet MSP RA21 (15.21 instead of 29.10) because early runs have timestamp_utc=null. Fix: fall back to folder timestamp when JSON timestamp is null.
  • 04 Extension agreement — need to contact professor to agree on extension topic before writing the report. Candidates: sliding window ablation, aspect ratio fix analysis, or Base vs Large systematic study.
